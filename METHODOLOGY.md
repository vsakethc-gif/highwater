# Methodology

How SC-5 Ready decides each status, step by step. This app is not an official warning system.

## Status levels

| Level | Name | Meaning |
|---|---|---|
| 0 | Normal | No active official alerts for this hazard here right now |
| 1 | Watch | Conditions could develop. Get ready. |
| 2 | Warning | It is happening or about to. Act now. |
| 3 | Danger | Life-threatening, extreme, or emergency-level alert |

The overall status for a place is the highest level among all hazards.

_The rules, thresholds, and data sources are added in Phase 2._
